# SQL Practice Queries 1–65

## Description
Practiced SQL queries using Employee, Department, and Project tables in DB Fiddle.

## Topics Covered
- Basic SELECT and WHERE queries
- String pattern matching using LIKE
- Date filtering and date functions
- Aggregate functions like SUM, AVG, MIN, MAX, and COUNT
- GROUP BY and HAVING clauses
- ORDER BY and LIMIT
- JOIN and LEFT JOIN operations
- Subqueries and nested queries
- Duplicate data checking
- Salary, age, and experience analysis
- Filtering using BETWEEN, IN, and NULL conditions

## Files
- datacreation.sql → creates tables and inserts sample data
- queries.sql → contains SQL queries (1–65)
- output.txt → contains outputs of executed queries

## Tools Used
- DB Fiddle
- GitHub

## Learning Outcome
Learned SQL basics and advanced concepts including filtering, grouping, joins, subqueries, sorting, and data analysis.
