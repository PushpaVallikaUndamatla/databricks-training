# SQL Practice Queries

## Description
In this practice session, I worked on different SQL queries using the Employees table in DB Fiddle. I practiced retrieving, filtering, grouping, and sorting data using various SQL concepts.

## Topics Covered
- SELECT queries
- WHERE conditions
- GROUP BY and HAVING clauses
- ORDER BY and LIMIT
- DISTINCT keyword
- Comparison and logical operators
- IN, NOT IN, and BETWEEN operators
- LIKE operator for pattern matching

## Files Included
- datacreation.sql → contains table creation and sample data
- queries.sql → contains all SQL practice queries
- output.txt → contains outputs of executed queries

## Learning Outcome
Through this practice, I gained better understanding of SQL basics and improved my ability to work with different types of queries and data filtering techniques.
